# Longcut

Десктопный инструмент для монтажа игровых лонгплеев без комментариев: режет сырые
записи на сегменты по сценам и движению, описывает каждый сегмент через Claude,
оценивает его значимость для истории (1–10) с учётом контекста и собирает
итоговый монтаж (mp4 + EDL / FCP7 XML для Premiere и DaVinci Resolve).

Стек: Go + Wails v2 (React/TS в нативном окне), ffmpeg, SQLite (modernc, без CGO),
Anthropic SDK. Один бинарник, никаких локальных серверов.

## Требования

- Go 1.26+, Node 20+, Wails CLI v2 (`go install github.com/wailsapp/wails/v2/cmd/wails@latest`)
- Windows: WebView2 (есть в Windows 10/11). macOS: Xcode Command Line Tools.
- ffmpeg + ffprobe: из PATH, из папки `<data>/bin`, либо кнопка «Скачать» в настройках.
- `ANTHROPIC_API_KEY` в окружении (или ввод в настройках на время сессии).

## Сборка

```sh
wails build                # build/bin/Longcut.exe | Longcut.app
go build -o bin/longcut ./cmd/longcut   # CLI
go test ./...              # тесты: детекция сцен, парсер JSON, хранилище, экспорт
```

## Данные

База проектов, кэш кадров и превью, скачанный ffmpeg и экспорт по умолчанию лежат в
папке данных. Она может занимать гигабайты, поэтому её можно перенести:

- в приложении: Настройки → Папка данных → «Изменить…» (с переносом существующих данных);
- из CLI: `longcut datadir D:\LongcutData` (без переноса).

Выбор сохраняется в `config.json` рядом с папкой по умолчанию
(`%LOCALAPPDATA%\Longcut` на Windows, `~/Library/Application Support/Longcut` на macOS).
Порядок приоритета: переменная `LONGCUT_DATA_DIR` → `config.json` → папка по умолчанию.

## CLI

```sh
longcut run -p kenshi-s1 -game Kenshi D:\Videos\kenshi     # всё: add → analyze → frames → describe → score
longcut status -p kenshi-s1                                 # прогресс, потрачено, оценка остатка
longcut segments -p kenshi-s1 -min-score 6                  # список с описаниями и оценками
longcut export -p kenshi-s1 -threshold 6 -out cut.mp4 -edl -xml
longcut describe -p kenshi-s1 -mock                         # сухой прогон без API, только оценка стоимости
longcut doctor
```

Любой этап можно прервать (Ctrl+C) и запустить снова: прогресс хранится в SQLite
по статусам сегментов, а каждый ответ API кэшируется по хешу входных данных
(модель, версия промпта, кадры / контекст), так что повторный запуск не платит.

## Как это работает

1. **Анализ** — ffmpeg отдаёт только ключевые кадры (GPU-декод, `-skip_frame nokey`),
   уменьшенные до 160×90 gray. В Go считаются межкадровое движение и расстояние
   гистограмм; жёсткие срезы, плавные переходы и смены активности дают границы.
   Сегменты 5–60 с. Полный декод 2 fps включается автоматически, если ключевые кадры
   реже 2.5 с.
2. **Кадры** — 3–5 кадров на сегмент, 1280×720 JPEG q70 (~1.2k токенов каждый).
3. **Описание** — `claude-sonnet-5` по умолчанию, 1–2 предложения на сегмент.
4. **Оценка** — та же модель, JSON `{"score", "reason"}` через structured outputs
   с контекстом 8 предыдущих сегментов. Ручная оценка и явное включение/исключение
   имеют приоритет.
5. **Экспорт** — stream copy через concat demuxer (срезы по ключевым кадрам, мгновенно)
   или перекодирование libx264 для покадровой точности; EDL CMX 3600 и xmeml.

Ориентир по стоимости для claude-sonnet-5: около $0.025 на сегмент, то есть ~$4–5 на
трёхчасовой лонгплей. Оценка показывается до запуска и после.
